## 👋 Sobre mim 👋

Sou **Natan Cardeal**, estudante de **Análise e Desenvolvimento de Sistemas na Fatec Ribeirão Preto**.

Minha trajetória começou no desenvolvimento de software e hoje estou direcionando minha carreira para a **análise de dados**. Quero unir programação, bancos de dados e análise para compreender problemas e apoiar decisões.

Tenho interesse em **oportunidades de estágio na área de dados**, nas quais eu possa desenvolver meus conhecimentos e contribuir com o que venho aprendendo na graduação e nos projetos.

Atualmente, desenvolvo o **LiteArt**, uma plataforma de preparação para vestibulares, e continuo praticando desenvolvimento web.

> **Desenvolvimento de Software + Dados + Aprendizado contínuo.**

### 🎓 LiteArt

Projeto autoral que começou como uma ideia durante o **Ensino Médio** e atualmente está sendo desenvolvido como um **MVP durante minha graduação**.

A proposta é criar uma plataforma digital de preparação para vestibulares, com previsão de utilizar IA para oferecer **feedback personalizado após as respostas dos estudantes**.

Meu trabalho envolve a definição dos requisitos, a organização da arquitetura, a construção de protótipos e o desenvolvimento da interface.

**Status:** em desenvolvimento. O feedback com IA faz parte da proposta do produto.
