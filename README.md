## 👋 Sobre mim

Sou **Natan Cardeal**, estudante de **Análise e Desenvolvimento de Sistemas na Fatec Ribeirão Preto**.

Minha formação começou pelo desenvolvimento de software, mas atualmente estou direcionando minha carreira para a **área de dados**, buscando unir programação, bancos de dados e análise para transformar informações em algo útil para projetos e decisões.

No desenvolvimento, tenho interesse em entender não apenas como uma aplicação funciona, mas também **como os dados são estruturados, armazenados e utilizados dentro dela**.

Atualmente, um dos principais projetos em que aplico esses conhecimentos é o **LiteArt**, uma plataforma de preparação para vestibulares que estou desenvolvendo durante a graduação.

> **Desenvolvimento de Software + Dados + Aprendizado contínuo.**

## 🚀 Projetos

### 🗺️ Mapa Interativo — ProEx 2024

Meu primeiro projeto de programação, desenvolvido durante o **Ensino Médio Técnico no Senac Ribeirão Preto** para a **ProEx 2024**.

A proposta era criar um mapa interativo para apresentar os locais e horários das apresentações da feira. Foi também um dos meus primeiros contatos com desenvolvimento web e marcou o início da minha jornada na programação.

> Um projeto simples, mas importante para entender de onde comecei.

### 🎓 LiteArt

Projeto autoral que começou como uma ideia durante o **Ensino Médio** e atualmente está sendo transformado em um **MVP durante minha graduação**.

O LiteArt propõe uma plataforma digital de preparação para vestibulares, utilizando IA para fornecer **feedback personalizado após as respostas dos estudantes**.

Atualmente estou trabalhando na definição dos requisitos, arquitetura, protótipos e validação da proposta.
